# Techanor

Techanor is a full-stack e-commerce platform for technology products.

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- MongoDB
- Mongoose

## Features

- User authentication
- Product browsing and filtering
- Shopping cart
- Order management
- Admin dashboard

## Architecture

Techanor follows a layered architecture with separate controllers,
services, models, schemas, routes, and middleware for maintainable
and scalable development.

## Development

This project is actively maintained and improved.

## Project Status

Techanor is continuously being improved with new features and refinements.
